# Анемона — лендинг цветочной мастерской (демо)

Статический сайт: HTML + CSS + чистый JavaScript. Сборка не нужна.

## Структура
```
anemona/
├─ index.html        — вся разметка
├─ css/style.css     — стили и анимации
├─ js/data.js        — товары, палитры, отзывы (демо-данные)
├─ js/art.js         — рисование букетов в SVG кодом
├─ js/main.js        — каталог, конструктор, корзина, лепестки, слайдер
├─ favicon.svg
└─ vercel.json
```

## Запуск локально
Просто откройте `index.html` в браузере (или `npx serve .`).

## Деплой на Vercel
1. Загрузите папку `anemona` в репозиторий GitHub и импортируйте его в Vercel
   (Framework Preset: **Other**, Build Command и Output Directory — пустые).
2. Либо перетащите папку на https://vercel.com/new или выполните `npx vercel` внутри папки.

## Что можно менять
- **Название, тексты, контакты** — `index.html`.
- **Товары и цены** — `js/data.js` (массив `PRODUCTS`).
- **Яндекс Карта** — в `index.html` у `<iframe>` измените параметры `ll=` и `pt=`
  (формат: долгота,широта). Координаты можно взять на yandex.ru/maps (правый клик по точке).
- **Настоящие фото вместо рисованных букетов** — положите картинки в `img/` и в `js/main.js`
  замените вызов `bouquetSVG(...)` на `<img src="img/...">`.
